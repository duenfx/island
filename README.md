Реалізовано:
1)У класі Main створила острів з розміром 10х10 для зручності. І тут запускається таймер ScheduledExecutorService, який запускає певні процеси життя на острові.
2)У клітинках острова живуть тварини та рослини. Для того, щоб уникнути помилок багатопоточності ШІ підказав ідею використати CopyOnWriteArrayList, що вирішило
проблему з помилками.
3)Усі тварини успадковані від базового класу Animal. Реалізовано 2 основні класи: Herbivore та Predator. Деякі травоїдні насправді також можуть їсти тварин(наприклад,
кабан), якщо рослин немає. Для цього я у методі eat для травоїдних поставила перевірку - якщо рослин у клітинці 0, то тварина йде полювати. Логіка харчування реалізована
у класі FoodChain.
4)Для тварин створено методи: eat, move, die, reproduce.
5)Статистика виводиться в консоль кожного дня: кількість рослин, тварин та таблиця з кількістю тварин у кожній клітинці. Вивід реалізовано через System.out.printf, щоб
стовпці таблиці були рівними незалежно від кількості цифр.
6)Рух тварин: щоб тварини не вилітали за межі масиву(IndexOutOfBound) додала перевірку координат за якою тварина потім або шукає інший шлях або стоїть на місці.
Нереалізовано:
1)Логіка розмноження для тварин.
2)Точне насичення тварин за таблицею. Зараз тварина отримує вагу з'їденої їжі, не враховуючи часткове або залишкове насичення.
3)Більш детальна статистика.
